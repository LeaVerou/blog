Every state of demo.svg

The same file, twelve times. --os is what the operating system says, --site is what the site has stored, and --states picks which control the site ships. The page inside the browser window resolves --site against --os. In the 2 states grid every row therefore contains two windows that render identically — under a light OS, --site: system and --site: light produce the same pixels. The only thing that tells them apart is the localStorage line underneath, which is not a thing users can see. Those are the choices the three-segment control asks them to make.
